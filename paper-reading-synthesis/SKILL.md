# 已有论文笔记整理

可直接调用。先读 [阅读与证据规则](../paper-reading/references/reading-rules.md)、[笔记约定](../paper-reading/references/note-format.md) 和 [思源格式](../paper-reading/references/siyuan-format.md)。

这里的 synthesis 指已有材料的整理和关联，默认不替用户完成研究思考，也不是粗读与入库之间必经的额外阶段。优先复用原文与核对过的笔记；只有旧笔记时可以做笔记级整理，但标明未复核原文，不提升其证据状态。不要求先生成粗读或精读产物。

用户要求应用联动时再读 [Zotero 与思源联动](../paper-reading/references/zotero-siyuan.md)。整理叙事时读取 [叙事脉络规则](../paper-reading/references/narrative-flow.md)。

## 归档内容

按 [类型适配](../paper-reading/references/paper-types.md) 保留实际重心，不把实证或 Benchmark 整理成方法论文。要放入画廊时用 [归档子 skill](../paper-reading-archive/SKILL.md)，目录由用户指定，未知先问，不自动归类。

- 以七部分格式消除重复，在一句话总结后保留论文叙事脉络，并保留关键定义、Observation、Insight、机制、假设和结果出处。只有旧笔记时，不补造其未记载的论证环节。
- 保留已核查的方法来源、本文改动、双侧原文定位和关系状态。只有「相似」线索时不在归档中升级为「继承」；需要补查来源时使用 [方法溯源](../paper-reading-lineage/SKILL.md)。
- 将方法涉及的设置条件、论文已报告的适用范围/成本/失效情况与相关结果放在一起，不自行推导迁移结论。
- 多篇材料实际可读时，可按统一事实维度并列问题、假设、机制、实验条件和结果；设置不同就注明，不强行排名或宣称谁取代谁。
- 用户真实提供的想法保留在独立的「用户批注」区，可整理原有措辞但不能补造观点；未核实事实与批注中的猜想仍保持未核实。
- 采用少量稳定的任务、方法、数据或理论关键词，沿用已有标签体系，记录材料中尚未解决的事实核查项。

不凭参考文献标题比较另一篇论文，不把单篇结果推广为领域结论。默认不写新颖性评价、最重要弱点、迁移方案、分析设想或完整实验计划。用户明确提出思考需求时才扩展，并按指定范围执行；思考问题只提问不代答。

按笔记约定交付，跨论文汇总保留各来源与版本。已有索引时更新关联，识别预印本与正式版，避免重复建档；不得编造思源文档 ID 或块引用。
