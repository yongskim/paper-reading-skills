# 论文阅读总入口

默认用中文讲清论文中的 Why、How、关键发现与证据，保留必要英文术语。先读 [跨领域适配](references/domain-adaptation.md) 和 [类型适配](references/paper-types.md)。不绑定学科、具体方向或已有领域目录；按实际贡献判断主/次研究类型，用它决定笔记结构。领域、研究类型和用户归档路径分别处理。

基础阅读只依赖用户提供或当前工具可访问的材料，可直接输出 Markdown，不要求特定应用或机器。Zotero、思源与指定 PDF 提取器是可选集成，连接与本地参数按 [运行配置](references/runtime-configuration.md) 获取；无配置时不假定已有连接。

## 两个日常场景

用户只需要说「粗读这篇」和「入库并精读，放到……」，不要求选择深度编号、子 skill 或重复列出输出模块。子 skill 是内部实现，在当前会话中读取执行，不代表子代理或新聊天。

### 先粗读，了解论文

「粗读」「快速看看」「先了解一下」以及未指定深度的普通「读这篇」默认调用速读说明，直接在聊天中给约 2–3 分钟可读完的概览：一句话、叙事主线、问题、核心认识、研究做法和主要证据。说明实际材料覆盖，不展开非关键公式、实现或外部来源检索。

这个阶段不启动归档、不问存放目录，不创建思源文档、画廊卡片或独立笔记文件；用户明确要求保存粗读结果时按该要求处理。「先粗读，感兴趣再入库」表示先完成粗读并等待用户后续指令，不由代理替用户决定是否感兴趣。

### 感兴趣后，入库并精读

用户说「入库」「收录这篇」「入库并精读」时，结合当前论文上下文执行精读与思源归档；仅表示感兴趣时不自动写入。没有先粗读也可以直接执行这一步。明确只归档现成笔记、只导入 Zotero 或只保存粗读时，遵从其较窄范围。

1. 沿用已核实的论文身份、版本、原文与有效转换产物，补读粗读未覆盖的关键章节、公式和证据。只在当前论文有歧义或无法取得此前原文时补问，不要求用户重新上传可访问材料。
2. 调用精读说明，补齐研究设计、关键机制/分析过程、适用条件、主要证据及实质来源核对。粗读摘要不能直接标为精读笔记；已存在核实过的精读内容时增量补充。
3. 调用归档说明。目录已明确就直接执行；未知时只问放到哪个目录，并可同时继续精读，目录确定前不写入思源。用户已说入库且目标已明确时，不再要求确认一次完整流程。
4. 在目标目录建立或复用同一篇论文子文档，写入精读笔记；关联 PDF 首页画廊、字段、文字索引与已有 Zotero 条目。保留用户批注，不为粗读、精读和卡片分别新建论文文档。
5. 读回核对后给笔记入口和完成情况。连接或材料不全时保留已完成笔记并说明剩余项，不把部分入库报告为全部完成。

用户明确要求「只精读、不入库」或只讲某模块时照办，不强制执行两步流程。

六个文件夹安装于同一 skills 目录。精读笔记约 5–10 分钟可读完，复杂核心内容可展开。来源核对和笔记整理按需内部调用，不把它们作为用户必须依次运行的额外步骤。

## 七部分的作用

1. 一句话总结。
2. Narrative Flow（叙事脉络）：紧接总结，讲清论文论证如何推进。
3. 问题与动机。
4. 核心认识与发现。
5. 问题定义与适用条件。
6. 研究设计与技术内容。
7. 证据与主要发现。

后四部分的实际标题和子项按类型变化：方法讲机制，实证讲测量，Benchmark 讲构建与评估协议，综述讲范围与分类，理论讲证明。不制造不存在的算法、目标函数或消融。

精读时关键来源也按类型追查：算法/架构、测量协议、数据/指标或分类框架分别对照前作，参照来源追查子 skill；不把标准技术正常使用等同于整篇贡献继承，也不根据未命中检索宣称原创。粗读只概述原文明示的来源，用户单独要求溯源时再展开。

## 共用约定

阅读 [证据规则](references/reading-rules.md)、[笔记约定](references/note-format.md)、[叙事规则](references/narrative-flow.md) 和 [思源格式](references/siyuan-format.md)。参考 [类型适配模板](assets/siyuan-note-template.md)。区分作者陈述、证据支持与阅读解释，保留原文位置和用户批注。

默认不追加弱点评审、研究启发、新方案或自问自答。作者明示的局限和材料缺口放相关内容旁。仅在用户要求时给 2–3 个思考题，不代答。

## 思源与 Zotero 衔接

用户要求入库时才按归档子 skill 衔接：本次目录未知先问，可以同时继续精读；目录已指定不重复询问。仅已连接思源、粗读或完整阅读都不单独构成入库指令。禁止按论文类型自动选目录或移动文档。

启用画廊时，可采用每个用户选定父页一个原生画廊、PDF 首页缩略图为封面，并按需填写字段；用户明确的布局与偏好优先。画廊和索引绑定同一篇子文档。实际实例与 ID 来自发布源码之外的本地配置，写前核验，不固定默认端口。

多领域共用文献库父文档。已有领域仅是目录实例，用户可指定其他领域或新方向；不要把配置中某个领域当作全局根或默认落点。新领域分类与字段按用户需要建立，不能复制旧领域分类。代码等专门字段不适用时可省略，现有字段和数据保持不变。

涉及 Zotero 或插件托管文档时读 [联动规则](references/zotero-siyuan.md)；归档细节见 [画廊规则](references/gallery-workflow.md)。复用已有工具，不默认安装插件、全库同步或批量导入。

完成时报告本次范围、实际材料覆盖、笔记位置及入库结果；未完成的原文核查或图像/索引写入单独说明。
