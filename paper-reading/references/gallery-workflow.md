# 分类页海报画廊与索引

本说明仅在请求思源画廊集成时使用。一种推荐布局是每个用户选定父页一个原生画廊、PDF 首页缩略图为封面；用户配置或本次选择优先。存放目录由用户指定，未知先问，不自动归类。内容类型与目录独立。

这是可扩展的多领域文献库。全局根为领域共同父文档，领域和具体画廊目标分别核验。用户可直接选择领域页或任意深度主题页，不要求所有领域都有同一套分类。见 [跨领域目录约定](domain-adaptation.md)。

## 对象关系

分类父文档包含画廊 AV 块及「论文索引」区域；每篇论文是该分类下的子文档。画廊主键绑定这篇文档，文字索引也引用它。PDF 仍可由 Zotero 管理，思源资源只保存所需缩略图。不要给同一篇分别创建卡片文档和笔记文档。

通用字段：论文（绑定文档主键）、阅读状态、封面、年份、期刊/会议/来源、作者、研究类型、关键词、原文/笔记链接、文献标识、加入日期。代码、数据、材料、研究对象等为按需领域字段。沿用已有列名和 ID，已有 Venue 列不强制改名，未知信息留空/待核验；不适用与未知分开。

## 思源 API 使用要点

- 所有写入经思源内核或现有连接器，不能直接改 `.sy` 或属性视图 JSON。跨实例先验证笔记本与目标文档身份。
- 创建文档用 `createDocWithMd`，输入路径是思源的人类可读路径；用户给出的磁盘存储路径用于定位现有文档，不能把它当作文档路径直接写文件。
- 向数据库绑定已有文档用 `addAttributeViewBlocks`，先渲染获得实际 item ID，再按类型写单元格；文档 ID 与 item ID 不假设相同。优先依当前版本公开接口及其返回结构执行。
- 封面字段是 `mAsset`，图像条目使用 `type: image` 及资源上传接口返回的路径。原生画廊配置应指向该字段，保持完整页面比例。
- 画廊读取返回 `cards`，表格读取返回 `rows`。不能在画廊模式只检查 rows 就认为未入库；过滤视图也不代表全库。
- 部分版本的画廊样式/字段操作需要内核 transactions。使用前核对实际版本和当前结构，写后渲染读回；此类内部操作不承诺跨版本稳定。
- 接口超时后先读当前状态，再决定是否补做。保留文档 ID、资源路径、AV/item ID 和完成阶段，避免因一次重试重复建文档或索引。

数据写入顺序：确认目录 → 身份查重 → 创建/复用子文档 → 上传封面 → 绑定/复用画廊行 → 填字段 → 追加/补充索引 → 读回核对。已有手写内容和其他论文行原样保留，新增论文不自动迁移原分类。
