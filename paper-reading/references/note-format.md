# 笔记格式与增量更新

## 默认交付

阅读前按 [跨领域规则](domain-adaptation.md) 确认术语、研究类型与证据语境，不绑定某个学科或现有目录。元数据中领域可以多选，Paper Type 不限于固定枚举；代码、实验、算法或指标等子项只在适用时出现。

粗读默认只在聊天中给简短概览，不额外建文件，也不启动思源归档。精读或入库时生成一篇可导入思源的 UTF-8 `.md` 笔记，或通过已连接工具直接写入并核对。内容和数学公式必须符合 [思源格式](siyuan-format.md)，每次输出前读取该规则。每篇论文保持一份完整笔记、七项主体功能，不把粗读、精读、卡片或章节拆成多个论文文档。用户既有结构或明确指定的格式优先。

主体顺序为：

1. 一句话总结
2. Narrative Flow（叙事脉络）
3. Problem & Motivation
4. 核心认识与发现
5. 问题定义与适用条件
6. 研究设计与技术内容
7. 证据与主要发现

模板见 [siyuan-note-template.md](../assets/siyuan-note-template.md)。只处理指定模块时保留对应编号/标题和必要上下文，不输出大量空标题。缺少核心材料时标注「原文未报告」「当前材料未覆盖」或「识别待核实」，区分三者。

第 4–7 部分的标题和子项按 [类型适配](paper-types.md) 选择，以上是功能说明。第 6 部分按需增加技术或研究设计来源，算法、测量、数据、指标或分类框架分别追查，见 [溯源子 skill](../../paper-reading-lineage/SKILL.md)。保留双侧出处和缺口，不强造不存在的方法。独立溯源不强制重写全篇。

先给一句话核心结论及紧凑的论文信息行，再给独立的叙事脉络，按 [叙事规则](narrative-flow.md) 呈现论证推进。默认不输出 YAML frontmatter、冗长管理信息或阅读流水账。粗读约 2–3 分钟可读完，可合并简短段落；完整精读笔记约 5–10 分钟可读完，重点机制可展开，入库时以此为子文档正文。

## 文件与已有笔记

遵从工作区交付目录规则。没有既有结构时可在交付目录保存 `paper-notes/paper-key.md`；使用稳定合法标识并检查同名冲突。只需聊天回答时不额外建文件；要求直接复制 Markdown 时用一个外层四反引号代码块呈现完整源码，内部公式仍使用普通美元定界符。

沿用用户已有笔记库、标签及命名，不强制迁移。保留原先的分层文件时在原文件中更新，可按用户需求合成单文档，不擅自删除旧文件。不同版本有关联但不混用公式/表格编号。

每次更新前确认论文身份及实际版本，读取已有内容；只补充选中模块，保留正确内容、手工标签、用户批注和链接。不用速读摘要覆盖精读解释。纠错写清原文依据；批注与原文冲突时保留原意并另注核实结果。

## 来源与覆盖

用简短信息行记 Title、Year、Venue、Research Area、Paper Type、实际版本和来源链接，只填可确认信息。类型可为 Method / Model / System / Attack / Defense / Empirical / Benchmark / Theory / Other，可按论文实际组合。

末尾只在必要时用简短说明记录实际读取材料、未覆盖模块或待核实位置。逐模块深度可放已有覆盖记录或独立索引；不要让覆盖表挤占笔记主体。整理已有笔记或创建入库记录不代表所有模块已精读，生成文件不代表全文已读完。

证据标记遵循 [reading-rules.md](reading-rules.md)。Section/Figure/Table/Equation 在相关事实附近直接写出，原编号不变；没有可信页码映射时不猜页码。

## 用户思考与思源写入

启用思源归档时参考 [画廊规则](gallery-workflow.md)，沿用用户布局与封面偏好，卡片和索引绑定同一子文档。读取源码之外的本地配置并核验实例后写入，不默认选择第一个端口；只需 Markdown 时不启动集成。

仅保留用户提供的个人想法，可置于「用户批注」区，无内容时省略。默认不添加思考题、批判分析或研究方向；明确要求思考题时给 2–3 个问题而不作答。

交付 Markdown 不等于直接写入思源。只有用户明确要求写入且有可用连接与已知目标时才执行；不直接编辑思源数据目录或伪造 `.sy` 文件。普通相对链接不会被承诺为思源块引用；已知真实块 ID 时才保留其原有引用。

涉及 Zotero 来源、文献索引数据库或 Citation 插件托管文档时读取 [联动规则](zotero-siyuan.md)，区分插件刷新区与人工/skill 笔记区，避免刷新覆盖笔记。
