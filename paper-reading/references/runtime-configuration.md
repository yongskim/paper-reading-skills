# 可移植运行配置

通用 skill 只包含流程及相对资源链接，不保存个人路径、端口或文档/数据库 ID。基础阅读不要求任何集成配置；缺少 Zotero、思源或 MinerU 时，使用已提供材料和当前可用的提取工具交付 Markdown。

## 配置发现

仅在请求集成或指定 PDF 提取工具时，按以下顺序查找：

1. 用户本次明确指定的配置文件或已连接工具参数。
2. 环境变量 `PAPER_READING_CONFIG` 指向的文件。
3. 当前工作区 `.paper-reading/siyuan.local.json`。
4. Codex 用户配置目录的 `paper-reading/siyuan.local.json`；配置目录由 `CODEX_HOME` 决定，未设置可使用 `~/.codex`。

这是通用发现约定，不假设盘符、用户名或应用数据目录。按平台解析路径，显式工具/配置优先。只读本次需要的配置，不搜索应用凭据文件。发布根目录 examples 中的空白示例应复制到源码之外再填写，不把私有配置覆盖回示例。

## 思源字段

`schema_version: 2` 的配置字段均可在不使用思源时省略：

- `base_url_hint` 是实际实例地址线索，不固定端口；写入前核对目标身份。
- `token_env` 是提供凭据的环境变量名称，不是真实密钥；使用时不输出值。
- `notebook_id`、`root_doc_id` 指实际笔记本和多领域文献库父文档。空值不代表已配置，入库时需由用户选择或实际核实。
- `domains` 是已有领域缓存，每项可有 `root_doc_id`、`root_title` 和 `galleries`。画廊缓存可包含 `parent_id`、`av_id`、`block_id`、`view_id` 和字段映射，不猜测生成这些现有 ID。
- `default_domain` 默认留空，优先用户本次指定目录，未知先问。缓存不是领域白名单。
- `field_policy` 采用通用元数据加按需扩展，保留已有字段与人工值。

旧配置若以单一领域为根，先确认共同父文档再迁移缓存；保留文档和画廊 ID，不搬动用户内容。

## PDF 与其他集成

优先遵从活动工作区指令。`pdf.preferred_extractor` 为 auto 或缺省时，选当前可用方式；`wrapper_path` 仅在用户明确配置时调用，后端按工作区或该配置决定。不假设固定盘符、PowerShell、CPU/GPU、模型缓存或 MinerU 已安装，不自动安装工具。

Zotero 优先使用当前已连接工具或用户提供的接口，不在共享技能中固定插件路径、个人目录或文库 ID。不可用时继续处理已提供材料，仅说明依赖连接的部分未完成。

本机工作区指令可以比公开技能具体；运行时遵从这些约束，不将其复制进发布源码。真实配置、私有映射与生成内容不随发布包分发。
