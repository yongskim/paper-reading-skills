# 论文画廊归档

先确定用户要放的目录，再将原文、首页卡片、索引和阅读笔记关联起来。在当前会话执行，不创建子代理。共用 [类型适配](../paper-reading/references/paper-types.md)、[笔记约定](../paper-reading/references/note-format.md)、[思源格式](../paper-reading/references/siyuan-format.md)、[来源联动](../paper-reading/references/zotero-siyuan.md) 和 [画廊操作约定](../paper-reading/references/gallery-workflow.md)。

## 确认目录与实例

用户本次已给明确目录时沿用；未给时先问「这篇放到哪个目录？」并列出当前相关目录。可以独立判断论文内容类型以写好笔记，但不得据此替用户选目录、移动文档或自动归类。用户选择实证目录不代表只能采用实证模板，结构以论文实际内容为准。

按 [多领域目录规则](../paper-reading/references/domain-adaptation.md) 区分文献库父目录、领域根与本次画廊父文档。配置里的领域和画廊仅是缓存，不是允许范围清单。用户可选择其他领域或新目录，不要求统一层级；只创建用户明确命名的缺失目录及本次需要的画廊，不复制旧领域的分类树。

连接与目标通过已连接工具或 [可移植运行配置](../paper-reading/references/runtime-configuration.md) 获取。显式配置、PAPER_READING_CONFIG、工作区本地文件及通用用户目录均可使用，不依赖某台机器的路径。真实 ID 与配置保存在发布源码之外，不保存密钥；没有思源连接时先交付 Markdown，不默认安装软件。

写入前用实际 API 核对目标笔记本 ID、根文档 ID 和分类父文档。端口可能随启动变化，配置中的地址只是线索；多个实例时不默认选第一个，也不固定默认端口。连接错误、身份不匹配或目录有歧义时停止写入并核对，已完成的阅读工作照常保存为 Markdown。

多领域配置使用 schema_version 2：root_doc_id 指共同的文献库父文档，domains 按领域保存各自 root_doc_id 与 galleries 映射；不要把任意一个 domains 条目的根作为全局默认。目标不在缓存中时读实际目录确认，在归档成功后补充对应领域记录，保留其他领域的 ID。

## 准备内容

通常的「入库」「收录」默认包含精读：调用 [精读说明](../paper-reading-deep/SKILL.md)，已有粗读时复用材料并补齐关键解释与证据，不能直接把粗读标成精读。已有完整精读笔记时增量维护，无需重复生成。用户明确只保存现成笔记或粗读时遵从该范围。根据实际论文类型调整第 4–7 部分，实证、Benchmark、综述、系统、理论不强套算法、训练和消融。

原始 PDF 按活动工作区规则及可用工具提取，再读取和生成笔记；配置了 MinerU wrapper 时遵从它，否则无需安装 MinerU。封面使用实际 PDF 首页缩略图并保持页面完整，不生成想象封面或总结海报；包装封面按用户选择处理。

关键词从实际内容提取。代码状态用「待核验 / 有代码 / 未发现公开代码」等可区分未知的状态；项目页、代码仓库与数据集链接分开，核实官方关联。没有核查不能把空链接解释成无代码。

画廊的通用元数据与领域专门字段分开。非计算类研究可使用数据/材料、研究对象或其他相关字段；代码不适用时留空或注明不适用，不能等同于未发现代码。沿用已有字段和人工数据，新增领域不必照搬所有旧字段。

Zotero 已有条目时关联真实父 itemKey、PDF 附件链接及已有笔记；输入只有外部 PDF 时不自动导入 Zotero。保留论文版本、DOI/arXiv 等身份供查重。

## 归档与验证

1. 按身份在目标范围查重；已有同篇笔记时复用，若在别的目录则告知位置，不擅自移动或再建一篇。
2. 在用户指定分类页下创建或增量更新论文子文档，采用类型适配的中文笔记。保留用户批注，不整文覆盖已有内容。
3. 上传首页缩略图到当前思源实例的资源目录；将分类页已有画廊的封面资源字段指向实际返回的路径。
4. 将子文档作为画廊中绑定文档的主键行，填写已核实字段。主键文档 ID、数据库条目 ID 与 AV ID 不混用。
5. 在分类页「论文索引」中添加真实子文档链接和简短介绍。已有相同目标链接则补充而不重复；画廊卡片与文字索引指向同一篇笔记。
6. 重新读取子文档、索引、数据库行与封面字段，核对链接、数值和用户目录。分别报告完成项和未完成项，不能仅凭请求返回 code 0 就宣称全部可见。

在目录选择尚未得到答复时，可先完成阅读和 Markdown，不创建子文档、上传附件或向数据库插入行。没有实际论文时不造示例卡片，也不批量导入既有文档。
